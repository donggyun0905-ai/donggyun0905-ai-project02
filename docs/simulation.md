# 테스트 계정 시뮬레이션

테스트 계정으로 로그인하면 오른쪽 위에 시뮬레이션 패널이 생긴다. 목표 점수를 정하고 시작하면,
가상의 사용자가 하루씩 앱을 쓴 기록을 **몇 분 안에** 실제 DB에 쌓는다. 대시보드·로드맵·등급이
몇 주~몇 달 쓴 사람처럼 바뀌는 걸 바로 확인할 수 있다.

## 누가 쓸 수 있나

- `USERS.is_test = TRUE`인 계정만 (일반 계정에는 패널이 안 보이고, 주소로 요청해도 403)
- 프로필에 **희망 직무**가 있어야 시작된다 (그 직무로 격차 분석·로드맵을 만든다)

## 쓰는 법

| 패널 | 하는 일 |
| --- | --- |
| 성향 | 새 판을 시작할 때 고른다. 비우면 무작위 |
| 목표 점수 · 등급 | 숫자를 넣거나 등급(취준생 500 · 실전러 1500 …)을 골라 채운다 |
| 시작 / 이어 하기 / 더 하기 | 목표까지 진행. 끝난 뒤 더 높은 점수를 넣고 "더 하기"를 누르면 이어서 간다 |
| 일시정지 | 진행 중인 하루까지만 마치고 멈춘다 |
| 초기화 | 두 번 눌러야 실행. 이 계정이 쌓은 데이터를 지우고 처음 상태로 |
| 화면 따라가기 | 켜면 방금 바뀐 화면으로 자동 이동하고, 진행이 하루 약 3초로 느려진다 |

진행 중에는 지금 보고 있는 화면의 숫자·글자만 새로고침 없이 바뀌고, 바뀐 곳이 잠깐 금색으로 빛난다.
끝나면 패널에 `달성! 21일 걸림`처럼 며칠 걸렸는지 나온다.

## 성향별 동작

| 성향 | 앱을 켜는 날 | 미션 정답률 | 로드맵 단계 완료 |
| --- | --- | --- | --- |
| 성실형 | 매일 95% 확률 | 90% | 3일에 한 번 |
| 보통형 | 매일 80% 확률 | 75% | 5일에 한 번 |
| 작심삼일형 | 3일 하고 2일 쉼 (하는 날도 90%) | 60% | 6일에 한 번 |

판마다 무작위 값이 새로 정해져서 **같은 조건이어도 결과가 매번 다르다.**
같은 판은 일시정지·더 하기로 이어 가도 흐름이 그대로 이어진다.

## 하루를 어떻게 판단하나

하루마다 아래 순서로 진행한다. 점수·연속 보너스·등급 계산은 **실제 사용자가 버튼을 눌렀을 때와 같은 코드**를 그날 날짜로 실행한다.

1. **오늘 앱을 켰나?** — 성향 확률로 정한다. 안 켠 날은 미션을 받지 않아 연속 기록이 끊긴다.
2. **미션 3문제** — 문제마다 정답률로 맞힘/실패를 정한다. 맞히면 등급별 점수, 다 끝낸 날이면 연속 보너스.
3. **로드맵** — 복습·트렌딩 학습 단계가 생길 때가 되면 추가하고, 켠 날이면 열린 것 하나를 기록으로 끝낸다.
   정해진 간격의 날에는 로드맵 다음 단계(기술·자격증·프로젝트)를 하나 끝낸다.
4. **스펙 점수 기록** — 그날 점수를 하나 남긴다 (대시보드 성장 그래프).
5. **목표 확인** — 총점이 목표 이상이면 멈춘다. 최대 365일까지만 돈다.

첫날에는 먼저 희망 직무로 격차 분석 → 로드맵 생성을 한다.

## 날짜는 어떻게 잡나

목표까지 걸릴 날 수를 성향별 하루 평균 점수로 **어림잡아 그만큼 전 날짜부터** 시작한다
(점수가 오를수록 하루 점수도 커지는 것까지 반영). 그래서 대개 오늘보다 며칠 전에 끝난다.
어림값이라 늦게 닿으면 오늘 이후 날짜까지 갈 수 있다.

## 초기화하면 지워지는 것

- 지움: 미션, 점수 기록·합계·등급, 연속 기록, 스펙 점수 기록, 격차 분석, 로드맵, 시뮬레이션이 프로필에 추가한 기술·자격증
- 남김: 계정, 시작 전에 있던 프로필
- 테스트 계정에 한해 **실제로 삭제**한다 (논리 삭제 예외). 다른 계정 데이터는 건드리지 않는다.

## 알아 둘 것

- `개척자`·`오디세이아`처럼 점수를 시드로 넣어 둔 계정을 초기화하면 그 점수도 0이 된다.
- 프로젝트 업데이트·기술 글 업데이트 단계는 실제 프로젝트·PDF가 필요해서 시뮬레이션이 끝내지 않는다.
- 진행 중에 새로 생긴 로드맵 카드의 버튼(증빙 제출 등)은 새로고침해야 눌린다.
- 서버를 다시 켜면 돌던 시뮬레이션은 일시정지 상태가 된다. "이어 하기"로 계속하면 된다.
