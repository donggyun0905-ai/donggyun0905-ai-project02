# 데스크톱 캐릭터(가이드) 계획서

바탕화면 어디서든 떠 있는 캐릭터가 **앞으로 할 일을 말풍선으로 알려 주는** 윈도우 프로그램.
봉고캣처럼 창 테두리·버튼 없이 캐릭터만 보이고, 내용은 전부 웹 서버에서 받아 온다.

> 상태 (2026-10-08): **구현 완료** — 바탕화면 캐릭터 · 웹 버튼 연결 · 할 일/알림/칭찬 말풍선 · 하루 요약 · 트렌드 순환 · 설정 창 · 연습장 연동 · 자동 실행 · 설치 파일(Setup.exe, 한국어) · 사이트에서 내려받기·업데이트 (파일은 DB 보관).
> 빌드·배포는 11절.

## 1. 정해진 것

| 항목 | 결정 |
| --- | --- |
| 형태 | 설치형 exe (웹·PWA로는 투명·테두리 없음·항상 위가 불가능해서) |
| 대상 OS | 윈도우만 |
| 만드는 기술 | Java 17 + Swing (추가 라이브러리 없이 투명 창 가능) · Gson · `jpackage`로 설치 파일 |
| 코드 위치 | 같은 저장소 `desktop-companion/` 폴더, 빌드 따로 (웹 war에 영향 없음) |
| 캐릭터 그림 | 팀에서 준비 (규격은 7절) |
| 데이터 | exe는 **DB에 직접 붙지 않고 서블릿 API만** 부른다 |

## 2. 전체 구조

```
[웹 사이트]  "캐릭터 연결" 버튼 ──→ specodyssey://connect?code=…&server=…
                                          │ (윈도우가 exe 실행)
[캐릭터 exe] ── code → 토큰 교환 ──→ [서블릿 /api/companion/*] ──→ 기존 서비스 ──→ DB
     │  1분마다: 할 일 목록 · 트렌드 · 연습장
     └─ 말풍선 표시 / 클릭하면 브라우저로 해당 화면 열기
```

말할 내용·조건은 **전부 서버가 정한다**. 문구를 바꿔도 exe를 다시 배포할 필요가 없다.

## 3. 연결(로그인) 흐름

1. 로그인한 사이트의 **오셍이들**(`/bot`)에서 **캐릭터 연결** → 서버가 이 사용자의 **일회용 코드(1분)** 를 만든다.
2. 브라우저가 `specodyssey://connect?code=…&server=…`를 연다 → exe가 켜진다. (처음 한 번 "앱 열기" 확인, "항상 허용" 가능)
3. exe가 `server`로 코드를 보내 **캐릭터 전용 토큰**으로 바꾼다. 코드는 즉시 폐기.
4. exe는 토큰을 `%APPDATA%\SpecOdyssey\`에 저장 → 다음부터는 자동 연결.
5. 사이트 **오셍이들 > 연결된 PC**에서 언제든 연결 해제(토큰 폐기). 같은 PC에서 다시 연결하면 예전 연결은 자동으로 끊긴다.
6. 연결한 브라우저에서 다른 계정으로 로그인하면 캐릭터가 그 계정으로 옮겨 가고, 로그아웃하면 쉰다 — 다시 연결할 필요 없음 (2026-10-08).

- 웹 로그인 세션(쿠키)은 넘기지 않는다 — 주소에 남으면 계정이 통째로 노출되고, 세션 만료 시 끊기므로.
- 토큰은 `SecureRandom`, DB에는 **해시만** 저장. 토큰으로는 그 사용자의 안내·트렌드·연습장만 읽고 쓸 수 있다.
- `server` 값을 같이 넘기므로 팀원마다 자기 PC 서버를 써도 그 서버에 붙는다.
- 이미 실행 중이면 새로 켜지 않고 실행 중인 캐릭터가 코드를 넘겨받는다 (한 번에 하나만 실행).

## 4. 캐릭터가 말하는 것

| 종류 | 언제 | 예 | 누르면 여는 화면 | 가져오는 곳 |
| --- | --- | --- | --- | --- |
| 놓치기 직전 경고 | 저녁(기본 20시)인데 오늘 미션 안 함 / D-day 3일 이내 | "연속 12일째! 미션 하나만 하면 이어져요" | 오늘의 미션 / D-day | MissionStreakService, DdayService |
| 새 할 일 | 오늘 미션 배정, 로드맵 다음 단계·복습·트렌딩 학습이 새로 열림 | "복습할 때가 됐어요: Spring Boot" | 로드맵 | DailyMissionService, GlanceService |
| 칭찬 | 등급 상승, 연속 7·30일, 로드맵 티어 완료 | "실전러 달성! 다음까지 1,422점" | 대시보드 | ScoreService, RoadmapService |
| 하루 요약 | 정한 시각(기본 9시) 또는 그날 처음 켤 때 | "오늘: 미션 3 · 로드맵 1단계 · D-3 정처기" | 대시보드 | GlanceService |
| 트렌드 기술 | 일정 간격마다, 하나씩 몇 초 보여 주고 다음으로 | "오늘의 트렌드: WebSocket — 실시간 양방향 통신" | 출처 링크 | TrendWidgetService (희망 직무 기준) |

- 여러 개가 겹치면 **경고 > 새 할 일 > 칭찬 > 하루 요약 > 트렌드** 순으로 하나씩.
- 서버는 말마다 고유 키(예: `mission-left:2026-10-06`)를 붙여 준다 → 같은 상황의 같은 말은 반복하지 않는다.

### 말풍선 끄기·다시 띄우기 규칙

- 캐릭터와 **의미 있는 상호작용**을 하면 말풍선이 꺼진다.
  - 말풍선의 ✕를 누름 / 말풍선을 눌러 화면을 엶 / **말한 일을 실제로 함** (다음 확인 때 서버 목록에서 그 키가 사라지면 자동으로 끔)
- 꺼진 시점부터 **30분 뒤**에 다음 말풍선. 이 간격은 설정에서 바꿀 수 있다 (5분~2시간).
- 트렌드 순환 간격·한 개당 보여 주는 시간, 하루 요약 시각, 저녁 경고 시각도 설정에서 바꾼다.
- **말풍선 기록**: 지금까지 띄운 말을 시간순으로 다시 볼 수 있다 (PC에 최근 100개 저장).

## 5. 조작

| 동작 | 결과 |
| --- | --- |
| 캐릭터 클릭 | 지금 가장 급한 할 일을 말한다 |
| 말풍선 클릭 | 브라우저로 해당 화면을 연다 |
| 캐릭터 드래그 | 위치 이동 (다음 실행 때도 그 자리) |
| 우클릭 메뉴 | 지금 할 일 · **연습장** · 말풍선 기록 · 조용히(1시간 / 오늘은 그만) · 숨기기 · 설정 · 연결 해제 · 종료 |

화면에 버튼은 띄우지 않는다 (말풍선의 ✕만 예외). 조용히 상태에서는 캐릭터가 조는 모습.

### 연습장(메모) 웹 연동

- 우클릭 → 연습장: 작은 메모 창. 로드맵 화면의 **연습장과 같은 내용**(NoteService — 서류 보관함 `연습장 노트.txt`).
- 열 때 서버에서 불러오고, 저장하면 서버에 저장 → 웹에서도 바로 보인다.
- 웹과 캐릭터에서 동시에 고쳤으면 저장할 때 "웹에서 바뀐 내용이 있어요"로 알리고 덮어쓸지 고르게 한다 (마지막 수정 시각 비교).

## 6. 서버 작업 (웹 프로젝트)

| 작업 | 내용 |
| --- | --- |
| 테이블 | `COMPANION_DEVICE` — user_id, token_hash, 일회용 code_hash·만료, 기기 이름, 마지막 사용 시각, 폐기 시각 + 공통 컬럼 (`sql/26`) |
| `POST /companion/connect` | 로그인 세션 필요. 일회용 코드 발급 → `specodyssey://` 주소로 이동 |
| `POST /api/companion/token` | 코드 → 토큰 교환 |
| `GET /api/companion/messages` | 지금 띄울 말 목록 (키·종류·우선순위·문장·여는 주소) |
| `GET /api/companion/trends` | 트렌드 기술 목록 |
| `GET` · `PUT /api/companion/note` | 연습장 불러오기·저장 (마지막 수정 시각 포함) |
| `POST /api/companion/disconnect` | 토큰 폐기 (exe의 연결 해제) |
| 오셍이들 화면 (`/bot`) | 캐릭터 소개 · 내려받기 · 캐릭터 연결 · 연결된 PC 목록 + 연결 해제 (2026-10-08, 예전 프로필 칸·메뉴 [캐릭터 켜기]를 옮김) |

- `/api/companion/*`은 세션 대신 토큰으로 확인하므로 `SessionFilter` 공개 경로에 추가해야 한다 → CLAUDE.md 규칙상 **리뷰어 2명**.
- 문장 만들기는 새 `CompanionMessageService` 한 곳에 모은다 (기존 서비스 호출만, SQL은 DAO에).
- 외부 API 호출 없음 — 전부 기존 DB 데이터로 만든다.

## 7. exe (`desktop-companion/`)

- 테두리 없는 투명 창, 항상 위, 캐릭터 밖 투명 영역은 클릭이 뒤로 통과.
- 1분마다 서버 확인 (서버가 꺼져 있으면 조용히 기다렸다 재시도, 말풍선에 오류를 띄우지 않음).
- 설정·토큰·말풍선 기록·위치: `%APPDATA%\SpecOdyssey\companion.json`
- 윈도우 시작 시 자동 실행 (설정에서 켜고 끄기).
- `specodyssey://` 주소 등록은 첫 실행 때 현재 사용자 레지스트리(HKCU)에 등록 — 관리자 권한 불필요.
- 설치 파일: `jpackage`로 Java를 함께 넣은 msi (사용자 PC에 Java 불필요, 약 50~80MB).

**캐릭터 그림 규격 (팀 준비)**: 투명 배경 PNG 또는 GIF, 약 160×160px, 동작 5가지 — 기본 · 말하기 · 기뻐하기(칭찬) · 놀라기(경고) · 졸기(조용히).

## 8. 진행 순서

| 단계 | 내용 | 끝나면 되는 것 |
| --- | --- | --- |
| 1 | exe 뼈대 — 투명 창, 캐릭터 표시, 드래그, 우클릭 메뉴, 말풍선 | 캐릭터가 바탕화면에 뜬다 (가짜 문장) |
| 2 | 연결 — 테이블, connect·token API, `specodyssey://` 등록, 프로필 연결 해제 | 웹 버튼으로 켜면 내 계정과 연결 |
| 3 | 말풍선 — messages API, 우선순위, 30분 규칙, 자동 꺼짐, 기록, 조용히 | 실제 할 일을 말한다 |
| 4 | 트렌드 순환 · 하루 요약 · 저녁 경고 · 설정 창 | 4절 전부 |
| 5 | 연습장 연동 | 캐릭터·웹 메모가 같아진다 |
| 6 | 설치 파일 · 자동 실행 · 실사용 점검 | 팀원 PC에 설치해 써 본다 |

## 9. 테스트

- 서버: 코드 1분 만료·한 번만 사용, 남의 토큰·폐기된 토큰 거절, 말 목록 우선순위·키, 연습장 동시 수정 감지 (JUnit)
- exe: 30분 규칙·자동 꺼짐·조용히 계산은 시계를 바꿔 끼워 단위 테스트
- 직접 확인: 설치 → 웹 버튼으로 연결 → 미션을 풀면 말풍선이 꺼지는지 → 30분 뒤 다음 말 → 연결 해제하면 끊기는지

## 10. 남은 결정·주의

- **범위**: 4주 웹 프로젝트 범위 밖의 추가 기능 — 팀 합의 후 진행. (질문에 답하는 챗봇이 아니라 알림형이라 "대화형 AI 멘토 보류" 항목과는 다름)
- **SessionFilter 공개 경로 추가**는 리뷰어 2명 필요.
- 코드 서명을 안 하면 설치·첫 실행 때 윈도우 "알 수 없는 게시자" 경고 (학습용이면 감수).
- 캐릭터 그림이 나오기 전에는 임시 그림(사이트 로고)으로 개발한다.

## 11. 빌드 · 배포 · 업데이트 (구현됨)

**바로 써 보기 (개발 중)**: IntelliJ에서 `desktop-companion/pom.xml`을 Maven 프로젝트로 추가하고 `CompanionApp`을 실행.
IDE 실행은 설치·`specodyssey://` 등록·자동 실행·업데이트를 하지 않는다 (exe로 실행했을 때만).

**설치 파일 만들기**
```
powershell -ExecutionPolicy Bypass -File desktop-companion\build-companion.ps1
```
→ `desktop-companion\dist\SpecOdysseyCompanion-Setup.exe` (약 47MB, Java 포함 — 이용자 PC에 Java 불필요). dist는 커밋하지 않는다.
- Setup.exe를 만들려면 빌드하는 PC에만 **WiX 3.14**가 필요하다: [wix314-binaries.zip](https://github.com/wixtoolset/wix3/releases)을
  `%LOCALAPPDATA%\wix314`에 압축만 풀면 된다 (설치·관리자 권한 불필요). 없으면 zip만 만든다.
- 설치 틀: `desktop-companion/installer/main.wxs`(jpackage 기본 틀 + `specodyssey://` 등록 + 설치 뒤 바로 실행),
  `MsiInstallerStrings_en.wxl`(설치 화면 문구를 한국어로 덮어씀).

**이용자 입장**
1. 사이트 **오셍이들** → **캐릭터 연결** → (설치 안 됐으면) **내려받기** → `SpecOdysseyCompanion-Setup.exe` 실행.
2. 내 계정에만 설치된다(관리자 권한 불필요): `%LOCALAPPDATA%\SpecOdysseyCompanion`, 시작 메뉴 "Spec Odyssey", `specodyssey://` 등록,
   윈도우 시작 시 자동 실행(설정에서 끌 수 있음). 설치가 끝나면 캐릭터가 바로 켜진다.
3. 다시 **캐릭터 연결** → 내 계정과 연결. 연결 정보는 `%APPDATA%\SpecOdyssey\companion.json` (업데이트·재부팅해도 유지).
4. 지우기: 윈도우 설정 → 앱 → "SpecOdysseyCompanion" 제거. (자동 실행 항목은 캐릭터 설정에서 먼저 끄면 깔끔하다)

**새 버전 내기**
1. `desktop-companion/pom.xml`의 `<version>`을 올린다 (예: 0.2.0).
2. 빌드 스크립트 실행 → Setup.exe.
3. 사이트 **관리자 → 데스크톱 캐릭터**에서 같은 버전 번호와 바뀐 점을 적고 Setup.exe를 올린다.
   DB(`COMPANION_RELEASE`/`_CHUNK`)에 8MB씩 나눠 저장되고, 최근 2개 버전만 남는다.
4. 사이트 [내려받기]가 바로 새 파일이 되고, 설치된 캐릭터는 켤 때·하루 한 번 확인해 "새 버전이 나왔어요 [업데이트]"를 띄운다.
   누르면 내려받기 → SHA-256 대조 → 설치 프로그램 실행(캐릭터는 꺼짐) → 새 버전으로 덮어쓰고 다시 켜짐.

- 코드 서명을 안 해서 처음 실행 때 윈도우 "알 수 없는 게시자" 경고가 뜰 수 있다 → "추가 정보 → 실행".

**설정 창 (캐릭터 우클릭 → 설정)**: 다시 말하는 간격(기본 30분) · 하루 요약 시각(9시) · 저녁 경고 시각(20시) ·
트렌드 순환 켜기/간격(10분)/보여 주는 시간(8초) · 크기 · 자동 실행.
