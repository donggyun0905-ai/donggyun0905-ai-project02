# 서류 보관함 실제 연결 · 프로젝트 완료 취소(표시만 해제) · 프로젝트 완료 시 받는 것(4-4)

날짜: 2026-10-01
관련 요구사항: FR-24 · FR-61~63 · 개발일지 4-4(프로젝트 완료 시 받는 것)

## 1. 서류 보관함 (`/documents`)
- 목록·올리기·내려받기·삭제·연결 프로젝트 변경을 실제 DB에 연결했다(`DocumentService`).
- 올릴 수 있는 형식은 허용 목록(pdf·doc·docx·hwp·hwpx·ppt·pptx·txt·md·png·jpg·jpeg·gif·zip), 파일당 20MB.
- 서류를 지우면 한 트랜잭션에서 ① 내 프로필의 이력서·자소서 지정, ② 프로젝트 문서 체크리스트의 그 줄을 같이 풀고,
  DB 커밋 뒤에 디스크 파일을 지운다. 로드맵 단계의 완료 표시와 받은 점수는 건드리지 않는다.
- 다른 사람의 서류·프로젝트에는 올리기·연결·삭제가 모두 막혀 있다(테스트 8개).

## 2. 프로젝트 단계 완료 취소 = 표시만 해제
- PROJECT 단계에도 "완료 취소" 버튼을 보여준다. 누르면 완료 표시만 풀리고, **프로젝트와 서류는 그대로 남는다.**
  파일을 지우려면 서류 보관함에서 지운다(확인 창에 그렇게 안내). 이미 받은 점수도 그대로(TD-5).
- 다시 완료하면 새 프로젝트를 또 만들지 않고, 단계에 연결된 프로젝트(`ROADMAP_STEP.evidence_project_id`)를 갱신한다.
  PROJECT 단계는 지금까지 이 연결이 없어서(완료할 때마다 새 프로젝트가 생겼다) `setEvidenceProject`로 채우게 했다.

## 3. 프로젝트 완료 시 받는 것 (개발일지 4-4)
PROJECT 단계와 CORE/ADVANCED 단계의 제출 폼이 같은 입력칸(`common/project-submit-fields.jsp`)을 쓴다.
- 코드 저장소 링크(`repo_url`)·배포 주소(`deploy_url`)·완료 회고(`retrospective`) — 선택. 링크는 http/https만 허용.
- 문서 체크리스트 7종(README·실행 화면·기획서·설계·API 명세·테스트 결과·발표자료) — 종류마다 "제출" 또는 "해당 없음".
  **README와 실행 화면 캡처는 필수**라 "해당 없음"이 안 되고 둘 다 제출돼 있어야 완료된다.
  이전에 낸 필수 서류가 아직 보관함에 있으면 다시 안 올려도 된다(보관함에서 지웠다면 다시 내야 한다).
- 기술 활용 설명서(`PROJECT_TECH_NOTE`) — 기술 이름 + 활용 설명(최대 5개). SKILL 마스터(이름·별칭)에 없는 기술은
  저장하지 않고 완료 후 안내 메시지로 알려준다.
- 이전에 낸 내용은 폼에 미리 채워지고, 검증에 실패하면 방금 입력한 값이 그대로 남는다.
- 검증은 트랜잭션 안에서 하고 실패하면 프로젝트·서류가 하나도 만들어지지 않으며, 서블릿이 디스크에 써 둔 파일을 지운다.

## 4. 바뀐 규칙 (기존과 다른 점)
- 예전에는 "증빙 파일 1개 이상"이 완료 조건이었는데, 이제 **README + 실행 화면**이 조건이다(4-4 확정안).
- `[TEST] 파일 없이 통과` 버튼은 그대로 있다(운영 배포 전에 지울 것).

## 6. 아직 안 한 것
- 면접관 타임라인에 저장소·배포 링크 노출.
- 기술 글 게시판(스키마만 있음).

## 7. 같은 날 이어서 — 로드맵 고정 레이아웃 · 가입 동의 · 기술 복습(끝없는 로드맵)
- 로드맵: 헤더 sticky, 좌우 박스(일일 미션·최근 서류 / 트렌드·연습장)는 화면 좌우 끝에 고정.
- 가입: 개인정보 수집·이용 동의(필수) + 지원자는 "면접관에게 보이는 자료" 숙지 체크(필수). 서버에서도 검사. 기존 계정 재동의는 아직 없음.
- **기술 복습**(`step_type=REVIEW`, 스키마 변경 없음): 끝낸 기술마다 주기가 지나면 대표 로드맵 맨 뒤에 복습 단계를 이어 붙인다.
  - 주기는 단계별 차등 — 도달한 가장 높은 단계 기준 입문 30 / 핵심 60 / 심화 90 / 전문가 120일. 기준 시각은 그 기술의 최근 완료(학습 또는 복습).
  - 열린 복습은 최대 3개, 한 기술당 1개. 로드맵 화면을 열 때 생성(멱등, LLM 비용 0).
  - 완료는 복습 기록 20자 이상 제출 — 체크만으로는 불가, 완료 취소 없음. 점수는 감쇠 40→30→20→10→5(최저 5).
  - 계단식 잠금(티어 진행도)에는 영향을 주지 않는다.
- 팀 확인이 필요한 값: 주기(30/60/90/120), 점수(40 기준 -10씩, 최저 5), 열린 복습 상한 3개 — `RoadmapService` 상수.
- 다음 단계(안 함): 작성한 프로젝트·기술 글 업데이트 제안, 트렌딩 신기술 학습 단계.
