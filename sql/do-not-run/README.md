# 실행 금지 SQL

이 폴더의 파일은 **공유 DB나 데이터가 들어 있는 DB에서 실행하면 안 된다.** 평소 DB 세팅에는 `sql/01~17`만 번호 순서대로 쓴다.

| 파일 | 왜 실행하면 안 되나 | 언제 쓰나 |
| --- | --- | --- |
| `schema_snapshot_2026-10-01.sql` | 모든 테이블을 `DROP TABLE` 한 뒤 **빈 테이블**로 다시 만든다. 문제(PROBLEM)·사용자·로드맵 등 모든 데이터가 사라진다. 첫 줄에 일부러 오류가 나는 `SELECT`가 있어서, 그 줄을 지우기 전엔 끝까지 실행되지 않는다. | 공유 DB에 못 붙는 환경(클라우드 세션 등)에서 **비어 있는 새 로컬 DB**에 구조만 만들 때 |
| `web_session_test_seed.sql` | 테스트 계정 `webtest`/`test1234`(약한 비밀번호)를 만든다. | 위 스냅샷으로 만든 **로컬** DB에서 로그인 테스트할 때만 |
| `spec_archive_test_accounts_seed.sql` | 스펙 아카이브 글쓰기 테스트용 계정(`개척자`/`오디세이아`, 비밀번호 `test1234`)을 만든다. 약한 비밀번호의 높은 티어 계정이라 공유·운영 DB에 있으면 안 된다. | 로컬 개발 DB에서 게시판 글쓰기를 시험할 때만 |

실수로 실행했다면: 데이터는 DB 백업이 있어야 되돌릴 수 있다. 저장소의 `sql/02~11` 시드로는 직무·기술·자격증·설문·등급·별칭 같은 기본 데이터만 다시 채울 수 있고, **문제(PROBLEM) 데이터는 저장소에 시드가 없다.**

참고: 스냅샷은 2026-10-01 기준(14번까지)이라 `sql/15`(PROJECT_LINK), `16`(복구 코드), `17`(점수 규칙)이 빠져 있다. 비어 있는 새 DB에 쓸 때는 스냅샷 뒤에 15~17도 실행한다.
