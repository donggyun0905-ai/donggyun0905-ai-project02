# 스펙 오디세이 화면 설계 — Figma 가져오기용 HTML

아티팩트 "스펙 오디세이 화면 설계"의 보드 7개를 독립 HTML 파일로 변환한 것입니다.
글자·크기·이미지는 원본과 같고, 아티팩트 전용 태그만 걷어냈습니다.

| 파일 | 화면 | 크기 |
| --- | --- | --- |
| 00_StyleGuide.html | 스타일 가이드 | 1200 x 1500 |
| 01_Landing.html | 홈 (비로그인) | 1440 x 760 |
| 02_Login.html | 로그인 | 1440 x 760 |
| 03_Signup.html | 회원가입 | 1440 x 1000 |
| 04_Profile.html | 내 프로필 | 1440 x 2340 |
| 05_Roadmap.html | 내 로드맵 | 1440 x 2020 |
| 06_Error.html | 오류 화면 | 1440 x 700 |

## 가져오는 방법 (html.to.design 플러그인)

1. Figma에서 **Design 파일**을 새로 엽니다 (Sites 파일에서는 플러그인이 안 뜰 수 있음)
2. 플러그인 html.to.design 실행
3. HTML 파일을 플러그인 창에 드래그 (또는 HTML 탭에 코드 붙여넣기)
4. 화면마다 반복. 뷰포트는 데스크톱(1440)으로

## Sites 파일로 옮기기

Design 파일에서 프레임을 복사(Ctrl+C)해서 Sites 파일에 붙여넣기(Ctrl+V)하면 됩니다.
프레임 너비가 1200~1600px이면 프레임을 오른쪽 클릭 → Copy to Figma Sites 도 가능합니다.

## 참고

- 폰트: Noto Sans KR, Noto Serif KR (없으면 플러그인의 누락 폰트 다운로드 옵션 사용)
- 이모지(나침반, 닻)는 텍스트로 들어옵니다. 필요하면 아이콘으로 교체하세요
- 무료 플랜은 html.to.design 가져오기가 30일에 10번까지입니다 (화면 7개면 한 번에 다 못 넣을 수 있음)
